给 PDF 留出笔记空白，在 iPad 或纸上写

讲义和教材排得满满当当，笔记只能挤在边上？PDFSpacer 在段落或幻灯片下方插入书写空间，让后面的内容向下移。你可以加一小段横线，也可以放一整页点阵纸，让笔记跟着对应的内容走。

免费，无需注册，无水印，PDF 在浏览器中处理，不会上传。编辑器使用英文，下方附有常用按钮对照。

打开 PDF，留出笔记空间

给 PDF 添加笔记空白的步骤

  1. 打开 PDF。在编辑器中点击 Open PDF，选择讲义、阅读材料或扫描教材。PPT 需要先保存为 PDF。
  2. 选择留白位置。点击 + Add space，再点击段落、图表或幻灯片下方的空隙。新增区域横跨页面，下方内容随之下移。
  3. 选择纸张样式。Plain 是空白，Ruled lines 是横线，Squared paper 是方格，Dot grid 是点阵。选中留白后按毫米调整高度和图案间距。
  4. 导出后记笔记。点击 Export PDF，选择 A4 分页或一张长页，下载后导入笔记应用，或直接打印。

iPad 笔记 PDF 留白：先排版，再手写

使用 GoodNotes、Notability、云记或享做笔记时，可以先把 PDF 留白，再通过应用的 PDF 导入功能打开。PDFSpacer 负责腾出位置，手写、打字和画图在笔记应用里完成。

选择 Single long page 可连续滚动；选择 Paginated A4 可逐页翻阅或打印。超长页的显示取决于笔记应用对页面尺寸的支持。

PPT 讲义加笔记区：每页下面加横线

如果 PDF 每页是一张幻灯片，点击 + Every page，选择 Fill the rest of the sheet 和 Ruled lines，再确认添加。导出 A4 时，幻灯片按页宽缩放，下方用横线填到页底；如果剩余不足 40 毫米，就多加一整页。

如果一页有多张幻灯片，+ Every page 只会在整页末尾加空间。要在每张幻灯片下面写笔记，用 + Add space 分别点击它们之间的空隙，先留出 60–90 毫米，再按需要调整。

给 PDF 加空白页、方格或点阵纸

需要大段推导或整理课堂总结，可以用 + Every page 的 Full blank page 在每页后插入空白页。用 Paginated A4 导出时，每张新增页都会从新的一页开始；纸张也能选横线、方格或点阵。

只需少量空间，可选择半页或自定义毫米高度；也可直接在某个段落下方插入留白。

隐藏不需要的部分，收起间隙

选择 ✂ Cut，拖选页面上的一条横向区域，下方内容就会上移。隐藏的内容不会显示或打印，但仍留在文件中，提取文字时仍可能读到，不能用来清除保密信息。

导出时，可取消末页的网站署名。

想给试卷留出答题区，可以查看PDF 添加空白与答题空间；其他操作见完整英文指南。

英文按钮怎么用

编辑器目前使用英文，常用按钮的含义如下：

  • Open PDF：打开设备上的 PDF。
  • + Add space：在点击的位置插入留白。
  • Select：选中留白，调整位置、高度和纸张样式。
  • ✂ Cut：拖选一条横向区域，将其隐藏并收起间隙；内容仍留在文件中。
  • + Every page：在每页末尾批量添加留白或整页空白。
  • Export PDF：导出调整后的 PDF。
  • Paginated A4 / Single long page：按 A4 分页 / 导出为一张长页。
  • Download layout：在 Project 菜单中下载布局文件；另存一份原始 PDF，以便继续编辑。

常见问题

怎样给 iPad 笔记用的 PDF 留白？

用 PDFSpacer 打开文件，选择 + Add space，在段落或幻灯片下方点击，再设置纸张样式和毫米高度。导出 PDF 后，导入笔记应用，就能在新增区域手写。

可以导入 GoodNotes、Notability、云记或享做笔记吗？

导出的是标准 PDF，可以通过笔记应用的 PDF 导入功能打开。可选 A4 分页或一张长页；若应用对超长页面有限制，选择 Paginated A4。

怎样给 PPT 讲义每页下面加横线？

先把 PPT 保存为 PDF，打开后点击 + Every page，选择 Fill the rest of the sheet 和 Ruled lines。横线会填到所在 A4 页的底部；剩余不足 40 毫米时，会新增一整页书写区域。

能在 PDF 每页后插入一整张空白页吗？

可以，在 + Every page 中选择 Full blank page，再用 Paginated A4 导出。新增空白页会从独立的 A4 页面开始，也可以换成横线、方格或点阵纸。

扫描教材和已经写过笔记的 PDF 可以用吗？

扫描教材可以留白，请在段落之间的空隙点击，避免穿过文字。导出会保留原有文字、矢量图形和扫描图像，不会把页面转成图片，但不会保留已有的批注、表单和可点击链接，因此请先留白，再添加笔记。

讲义 PDF 会上传吗？要注册或付费吗？

免费使用，无需账号，无水印，PDF 在浏览器中处理，不会上传。页面会从 CDN 加载 PDF 库，并发送不使用 Cookie 的浏览和导出次数统计；两者都不会接触你的 PDF。

下次还能继续调整留白吗？

可以，在 Project 菜单中点击 Download layout，保存布局文件，并保留原始 PDF。下次打开同一份原始 PDF，再加载布局即可继续调整；布局文件本身不含 PDF。
