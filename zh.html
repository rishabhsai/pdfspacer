打开 PDF，添加留白

怎样给 PDF 添加空白

  1. 打开文件。进入编辑器，点击 Open PDF，选择试卷、练习题或讲义 PDF，扫描件也可以。
  2. 点击需要留白的位置。选择 + Add space，在题目或段落下方的空隙点击。选择纸张样式，拖动底部手柄调整高度，尺寸以毫米显示。
  3. 导出 PDF。选择 Paginated A4，得到可打印的 A4 页面；或选择 Single long page，得到适合平板连续滚动的一张长页。

试卷留白、PPT 讲义加笔记区

  • 给 PDF 试卷增加答题空间。简答题下加横线，计算题下加方格，每道题的留白高度可以单独调整。
  • 给 PPT 讲义加笔记区。先将 PPT 保存为 PDF，再用 + Every page 在每页下方批量添加横线。选择 Fill the rest of the sheet，可把幻灯片下方到 A4 页底的空间填满；剩余不足 40 毫米时，会多加一整页。
  • 在 PDF 每页后插入空白页。用 + Every page 选择 Full blank page，一次添加整页空白；也可选择半页或自定义毫米高度。
  • 给 iPad 笔记 PDF 留白。为讲义和阅读材料留出批注位置，导出后再导入笔记应用。查看在 iPad 或纸上记笔记的留白方法。

留白跟着内容走

  • 插在页面内部。书写区域横跨页面，放在你选的题目或段落下面；也能批量加空白页，无需改变侧边页边距。
  • 四种纸张样式。空白适合草图，横线适合文字，方格适合演算，点阵适合画图和整理思路。
  • 保留原稿清晰度。原有文字和矢量图形直接保留，导出时不会栅格化为图片。
  • 在本地处理文件。PDF 在浏览器中处理，不会上传。页面会从 CDN 加载 PDF 库，并发送不使用 Cookie 的浏览和导出次数统计；两者都不会接触你的 PDF。

英文按钮怎么用

编辑器目前使用英文，常用按钮的含义如下：

  • Open PDF：打开设备上的 PDF。
  • + Add space：在点击的位置插入留白。
  • Select：选中留白，调整位置、高度和纸张样式。
  • ✂ Cut：拖选一条横向区域，将其隐藏并收起间隙；内容仍留在文件中。
  • + Every page：在每页末尾批量添加留白或整页空白。
  • Export PDF：导出调整后的 PDF。
  • Paginated A4 / Single long page：按 A4 分页 / 导出为一张长页。
  • Download layout：在 Project 菜单中下载布局文件；另存一份原始 PDF，以便继续编辑。

常见问题

怎样给 PDF 试卷留白，增加答题空间？

打开 PDF，选择 + Add space，再点击题目下方的空隙，设置留白高度和样式。插入点下方的内容会向下移动，答案可以直接写在题目下面。

怎样在 PDF 每页后插入空白页？

点击 + Every page，选择 Full blank page 和纸张样式，再确认添加。用 Paginated A4 导出时，每张新增空白页都会从新的 A4 页面开始。

PDF 可以加横线、方格或点阵吗？

可以，留白有空白、横线、方格、点阵四种样式。选中留白后，可以按毫米调整高度和线条、方格或点阵的间距。

试卷 PDF 会被上传吗？

PDF 在浏览器中处理，不会上传。页面会从 CDN 加载 PDF 库，并发送不使用 Cookie 的浏览和导出次数统计；两者都不会接触你的 PDF。

需要付费或注册吗？导出有水印吗？

免费使用，无需账号，导出没有水印。导出窗口中默认勾选的末页网站署名可以取消。

扫描版试卷也能添加空白吗？

可以，扫描页也能在选定的位置分开并插入留白。请点击题目之间的空隙，避免穿过文字；扫描件仍是原来的图像，不会变成可编辑文字。

Cut 会彻底删除题目或答案吗？

不会，✂ Cut 只是隐藏拖选的横向区域，并让下方内容上移以收起间隙。被隐藏的内容仍留在导出文件中，提取文字时仍可能读到，因此不能用它清除保密内容。

添加留白后，怎么打印或在平板上写？

用 Paginated A4 导出后可按 A4 打印；想在平板上连续滚动，可以选 Single long page。原有文字和矢量图形保持清晰，不会转成图片。
