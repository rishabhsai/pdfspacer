# Get started with PDFSpacer

Send the user this three-sentence walkthrough, then call `open_pdf_editor` with
`{}` so they can try it:

"PDFSpacer adds plain, ruled, squared or dot-grid writing space between the
questions of a PDF, and the PDF stays in ChatGPT and on your device. Choose a
PDF in the editor, select Add space, click in the gap below a question, and
export as A4 pages or one long page. In the ChatGPT desktop app you can also
open a PDF from a chat with PDFSpacer, and Save to ChatGPT replaces that file
with the spaced version."

If the user installed PDFSpacer during an existing task, continue that task
after opening the editor. Do not claim that any PDF was uploaded or edited.
